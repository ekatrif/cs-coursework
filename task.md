## Библиотека для удобной работы с цепочкой асинхронных вызовов

Необходимо реализовать библиотеку, которая предоставляет удобный API для работы с цепочками асинхронных вызовов. Идея в том, чтобы работать с данными так, как будто они уже доступны синхронно, вызывая методы напрямую. Например, обращение к свойству массива должно позволять вызвать любой метод массива, хотя фактически эти вызовы будут выполняться на промис-объекте, который в будущем вернет этот массив.

Ключевое требование — библиотека должна корректно выводить типы на основе данных. Она должна понимать тип каждого возвращаемого значения, поддерживать соответствующие методы и свойства, а также позволять расширять эту поддержку новыми типами. Библиотека должна быть гибкой, расширяемой и эффективной.

### Пример (ваш API может отличаться)

```js
// Возвращается структура данных {user: {name: ["Bob", "Smith"]}}
const request = fetch("/my-resource");

const scheme = {json: () => {data: {user: {name: [String]}}}};

// Каждый геттер или метод возвращают промис
const p = async(request, scheme).json().data.user.name[0].toLowerCase();

p.then((result) => {
  // "bob"
  console.log(result);
});
```
